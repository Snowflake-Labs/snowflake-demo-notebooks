# Run in Streamlit in Snowflake

In Snowsight, open Projects > Workspaces, select Add new > Streamlit App,
and name it `semantic_analytics`. Choose the lab role, an administrator-approved
compute pool, and `AGENTIC_ANALYTICS_VHOL_WH` as the query warehouse. Select
`SV_VHOL_DB.VHOL_SCHEMA` for the deployment location.

Replace the generated main Python file with `streamlit_app.py`. Retain the
configuration generated by Workspaces rather than copying a manifest from another
account. This app uses Streamlit, pandas, requests and snowflake-snowpark-python.
Check the runtime's installed packages before adding a dependency file. Additional
PyPI downloads may require an administrator-approved external access integration.

Select Run for a private development preview. Test Explore metrics and Ask a
question. Deploy creates a runnable version; it does not automatically grant other
roles access. Keep this teaching app private while it uses the lab owner role.

The SQL interface runs only queries assembled from discovered definitions. The
Analyst interface shows generated SQL for review and execution in a separate SQL
file; it never automatically executes model output with owner privileges.
The documented container token is read per request and never printed or cached.

No notebook session, password, token input, broad internet rule, or `_snowflake`
module is required. The compute pool runs Python; the warehouse runs SQL. Stop the
preview when finished, and remove any deployed app before deleting the lab.
